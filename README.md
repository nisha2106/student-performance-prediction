# Student Performance Prediction System

This project predicts student performance using machine learning.

## Files

- app.py - Application file
- train_model.py - Trains the machine learning model
- test_data.py - Tests the model
- student_performance.csv - Student dataset
- student_risk_model.pkl - Trained machine learning model
- requirements.txt - Required Python libraries
- openproject.bat - Project startup file

## Technologies

- Python
- Machine Learning
- Pandas
- Scikit-learn
